### 🔹 Q1. Cartesian to Spherical Coordinate Transformation

In three-dimensional space, a point can be represented using different coordinate systems.
This problem focuses on converting **Cartesian coordinates (x, y, z)** into **Spherical coordinates (r, θ, φ)**.

This transformation is mathematically important because spherical coordinates simplify problems involving:

* Radial symmetry
* Circular motion
* 3D spatial analysis

📌 The notebook demonstrates:

* Mathematical conversion formulas
* Step-by-step computation
* Example-based validation

👉 🔗 **[Open Solution Notebook](https://github.com/TanveeSP/Astronomical_Calculations/blob/main/Notebooks/A1Q1.ipynb)**

### 🔹 Q2. Astronomical Coordinate Conversion 🌌

This problem extends coordinate transformation into a **real-world astronomical context**.

A star’s position is given in Cartesian coordinates, which is then converted into spherical coordinates for better interpretation.

Spherical coordinates are widely used in astronomy because they describe:

* Distance from origin (r)
* Angular position in space (θ, φ)

📌 Real-world relevance:

* Space research
* Satellite navigation
* Astrophysics calculations

📌 The notebook includes:

* User input handling
* Conversion logic
* Practical examples

### 🔹 Q3. Projectile Motion Analysis 🚀

This problem models **motion of an object under gravity**, one of the most important concepts in physics.

The program accepts:

* Initial velocity (u)
* Angle of projection (θ)
* Acceleration due to gravity (g)

Using these inputs, the motion of the projectile is analyzed.

📌 The notebook computes:

* Time of flight
* Maximum height
* Horizontal range
* Trajectory path

📌 Visualization:

* Graphical representation of projectile motion

📌 Applications:

* Engineering
* Ballistics
* Sports physics

👉 🔗 **[Open Solution Notebook](https://github.com/TanveeSP/Astronomical_Calculations/blob/main/Notebooks/A3Q3.ipynb)**

### 🔹 Q4. Exponential Function Analysis 📈

This section explores the behavior of exponential functions, which are widely used in scientific and engineering domains.

Functions analyzed:

* f(x) = e^x → Represents exponential growth
* f(x) = e^(-x) → Represents exponential decay

📌 The notebook focuses on:

* Evaluating function values over a range
* Plotting graphs for visualization
* Understanding growth vs decay behavior

📌 Real-world applications:

* Population growth models
* Radioactive decay
* Machine learning activation functions

👉 🔗 **[Open Solution Notebook](https://github.com/TanveeSP/Astronomical_Calculations/blob/main/Notebooks/A4Q4.ipynb)**

### 🔹 Q5. Combined & Gaussian Function Analysis 🔬

This problem introduces more complex functions and their behavior.

Functions included:

* f(x) = x * e^(-x)
* Gaussian Distribution:
  f(x) = 1 / sqrt(2πσ) * e^(-x² / 2σ²)

The Gaussian function (Normal Distribution) is one of the most important concepts in statistics and data science.

📌 The notebook demonstrates:

* Behavior of combined exponential function
* Effect of varying σ (standard deviation)
* Shape and spread of Gaussian curves

📌 Applications:

* Data science
* Probability theory
* Signal processing

👉 🔗 **[Open Solution Notebook](https://github.com/TanveeSP/Astronomical_Calculations/blob/main/Notebooks/A5Q5.ipynb)**
